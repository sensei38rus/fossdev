make create_venv - создает виртуальное окружение
make install_deps - устанавливает зависимости, проверяя импорты в main.py и requirements.py через check_requires
make check_requires - запускает скрипт проверки импортов  в main.py и requirements.py
make app - запускает main.py
make typechek - проверяет типы в calc.py
make format - форматирует main.py
make build - главная команда которая соединяет в себе все предыдущие
